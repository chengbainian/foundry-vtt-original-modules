# AI-assisted authorship and review

This repository contains original Foundry VTT modules and a maintainer-requested integration. AI assistance was used to generate or revise code, documentation, tests, and in some projects bundled visual assets. `Cuujm` supplied requirements, directed iterations, and is the repository maintainer. Module-level notes identify third-party upstream code and assets separately; AI involvement does not change their original licenses or authorship.

Each module is independently installable and has its own license and provenance note. The combined Battle Transitions package contains upstream MIT-licensed code and is not represented as wholly original. Modules whose redistribution rights are not established are not included.
