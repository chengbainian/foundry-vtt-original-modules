# Foundry VTT 模组

本仓库中的模组由 AI 编写或协助编写，需求与修改方向由维护者提出并确认。

| 模组 | 作用 |
| --- | --- |
| LA 职业生命骰锁定（LA Hit Dice Lock） | 将 LA 等级计入角色总等级，并锁定对应职业的生命骰与普通职业成长。 |
| 私密羊皮纸（Private Parchment） | 让 GM 向指定玩家发送包含文字、图片或视频背景的私密消息。 |
| 引爆疯狂视觉效果（Madness FX） | 配合宏，在玩家端显示随疯狂层数变化的屏幕效果。 |
| 场景时空漩涡转场（Scene Warp Transitions） | 场景切换时播放红移／蓝移漩涡效果。 |
| 战斗转场与时空漩涡合并版（Battle Transitions + Scene Warp） | 整合战斗转场与时空漩涡效果，并提供电影转场效果包管理。 |
